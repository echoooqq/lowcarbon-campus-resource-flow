# 需求规格说明书 — 低碳校园资源循环流转桌面系统

> 版本：v1.0 | 最后更新：2026-11-08 | 依据：《软件构造》分组实验要求文档

---

## 一、项目背景

当前校园存在大量闲置教材、数码配件、文体用品、生活物资闲置浪费现象，二手流转信息零散，缺少轻量化本地桌面管理系统。本系统面向高校校园场景，实现闲置物品发布、分类检索、供需匹配、交易记录、信用评价、数据统计，并支持管理员后台管理，形成完整业务闭环。

---

## 二、用户角色

| 角色 | 说明 |
|------|------|
| 普通学生用户 | 注册登录后可发布/检索/收藏物品、发起流转、互相评价 |
| 系统管理员 | 管理用户账号、维护物品类别、下架违规物品、查看全平台流转统计 |

---

## 三、功能需求清单

### 3.1 用户账号模块

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| U-01 | 用户注册 | 匿名 | 输入用户名、密码、确认密码；用户名唯一校验；密码加盐 SHA-256 加密存储 |
| U-02 | 用户登录 | 匿名 | 用户名 + 密码登录；校验密码哈希；记录登录状态 |
| U-03 | 角色区分 | 系统 | 注册默认为普通用户；管理员通过数据库手动设置 role 字段 |
| U-04 | 密码修改 | 登录用户 | 验证旧密码后设置新密码 |
| U-05 | 信用分数 | 系统 | 初始 100 分；完成流转后根据评价加减分；展示在用户信息中 |
| U-06 | 输入合法性校验 | 系统 | 用户名 3-20 字符（字母数字下划线）；密码 6-50 字符；所有输入做长度限制和 SQL 注入防护 |

### 3.2 闲置物品发布管理

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| I-01 | 发布闲置物品 | 普通用户 | 填写：名称、分类、描述、价格、交易类型（售卖/交换）、标签；物品归属当前用户 |
| I-02 | 修改物品信息 | 普通用户 | 只能修改自己发布的物品；未成交物品可编辑 |
| I-03 | 下架物品 | 普通用户 | 只能下架自己的物品；下架后不展示在列表中 |
| I-04 | 物品状态管理 | 系统 | 状态枚举：`ON_SALE`（在售）、`RESERVED`（已预订）、`SOLD`（已成交）、`OFF_SHELF`（已下架） |

### 3.3 物品检索与筛选

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| S-01 | 分类筛选 | 全部 | 按物品分类筛选 |
| S-02 | 关键词模糊搜索 | 全部 | 对物品名称和描述做模糊匹配（SQL LIKE） |
| S-03 | 价格区间筛选 | 全部 | 设置最低/最高价格过滤 |
| S-04 | 列表展示 | 全部 | 表格形式展示物品列表，显示名称/分类/价格/状态/发布人/信用分 |
| S-05 | 收藏物品 | 普通用户 | 可收藏/取消收藏；收藏列表独立管理 |

### 3.4 供需沟通与流转记录

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| T-01 | 发起意向 | 普通用户 | 对感兴趣的物品发起交换/购买意向；物品状态变为 RESERVED |
| T-02 | 生成流转记录 | 系统 | 发起意向后自动创建流转记录；记录发起方、物品、时间 |
| T-03 | 流转状态管理 | 系统 | 状态枚举：`PENDING`（待确认）、`CONFIRMED`（已确认）、`COMPLETED`（已完成）、`CANCELLED`（已取消） |
| T-04 | 历史记录查询 | 普通用户 | 查询自己发起的和收到的流转记录 |

### 3.5 用户评价模块

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| R-01 | 双向评价 | 普通用户 | 流转完成后，买方和卖方互相评价；评分 1-5 星 + 文字评论 |
| R-02 | 信用分更新 | 系统 | 评价提交后更新双方信用分（+/- 评价分数差值） |
| R-03 | 查看评价 | 全部 | 物品详情和用户信息中展示历史评价 |

### 3.6 数据统计功能

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| ST-01 | 流转数量统计 | 全部 | 按分类/时间统计物品流转总量 |
| ST-02 | 低碳减排估算 | 全部 | 根据成交物品估算资源节约量（教材/数码/文体/生活物资分别设定系数） |
| ST-03 | 生成统计报表 | 全部 | 数字展示 + 简单图表 |
| ST-04 | CSV 导出 | 全部 | 导出统计数据为 CSV 文件 |

### 3.7 管理员后台

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| A-01 | 用户管理 | 管理员 | 查看用户列表、禁用/启用用户账号 |
| A-02 | 违规物品下架 | 管理员 | 强制下架违规物品 |
| A-03 | 类别维护 | 管理员 | 增删改物品分类 |
| A-04 | 全平台流转统计 | 管理员 | 查看全平台汇总数据（所有时间段、所有用户） |

### 3.8 拓展加分功能（选做）

| 编号 | 功能 | 说明 |
|------|------|------|
| E-01 | 本地数据备份与恢复 | SQLite 数据库文件复制/恢复 |
| E-02 | 关键操作日志 | 记录登录、发布、流转、评价等关键操作 |
| E-03 | 图片本地存储 | 物品图片本地存储（可选，需要时引入图片处理） |
| E-04 | 智能推荐 | 根据浏览和流转历史推荐物品 |

## 四、非功能性需求

| 类别 | 要求 |
|------|------|
| 性能 | 常规查询响应 < 2 秒；SQLite 单文件数据库，桌面单机使用无需高并发 |
| 安全 | 密码加盐 SHA-256 加密存储；所有 SQL 使用 PreparedStatement 防注入；输入长度和格式校验 |
| 可维护性 | 模块化分层架构；代码坏味道消除；统一异常处理；设计模式应用 |
| 可扩展性 | DAO 接口与实现分离；Service 层可替换；GUI 面板可独立替换 |
| 可用性 | Swing GUI 界面直观；菜单/弹窗/表格交互；中文界面 |
| 可移植性 | 纯 Java + SQLite；JDK 21 环境下双击 Jar 可运行；Windows/macOS/Linux 均可部署 |

## 五、业务流程概述

### 5.1 物品发布流程
用户登录 → 进入发布界面 → 填写物品信息（名称/分类/描述/价格/交易类型/标签）→ 校验 → 保存 → 物品进入列表展示

### 5.2 物品流转流程
浏览物品列表 → 搜索/筛选 → 查看详情 → 发起意向（交换/购买）→ 生成流转记录 → 物品状态变为 RESERVED → 对方确认 → 完成流转 → 状态变为 COMPLETED → 双方互相评价

### 5.3 评价与信用分流程
流转完成 → 双方进入评价界面 → 评分 + 文字 → 提交 → 更新双方信用分 → 评价记录保存 → 信用分展示在物品/用户信息中
