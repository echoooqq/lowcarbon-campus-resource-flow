# 数据库设计 — 低碳校园资源循环流转桌面系统

> 数据库：SQLite 3.x | 数据库文件：`lowcarbon.db` | 版本：v1.0 | 最后更新：2026-11-08

---

## 一、表总览

| 表名 | 说明 | 字段数 |
|------|------|--------|
| `user` | 用户账号表 | 7 |
| `category` | 物品分类表 | 3 |
| `item` | 闲置物品表 | 10 |
| `transaction_record` | 流转记录表 | 7 |
| `review` | 评价表 | 7 |

**全部表使用 `INTEGER PRIMARY KEY AUTOINCREMENT` 作为主键**，SQLite 会自动处理。

---

## 二、表结构详细设计

### 2.1 user — 用户表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `user_id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 用户唯一标识 |
| `username` | VARCHAR(50) | NOT NULL UNIQUE | 登录用户名，3-20 字符 |
| `password_hash` | VARCHAR(128) | NOT NULL | SHA-256 加盐后的密码哈希（64 hex 字符 + salt） |
| `salt` | VARCHAR(32) | NOT NULL | 随机盐值（16 字节 hex） |
| `role` | VARCHAR(10) | NOT NULL DEFAULT 'USER' | 角色：`USER` 普通用户 / `ADMIN` 管理员 |
| `credit_score` | INTEGER | NOT NULL DEFAULT 100 | 信用分数，初始 100 |
| `create_time` | INTEGER | NOT NULL | 注册时间戳（毫秒） |

**索引**：
```sql
CREATE INDEX idx_user_username ON user(username);
CREATE INDEX idx_user_role ON user(role);
```

---

### 2.2 category — 物品分类表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `category_id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 分类唯一标识 |
| `name` | VARCHAR(50) | NOT NULL UNIQUE | 分类名称（如：教材、数码配件、文体用品、生活物资） |
| `description` | VARCHAR(200) | NULL | 分类描述 |

---

### 2.3 item — 闲置物品表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `item_id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 物品唯一标识 |
| `publisher_id` | INTEGER | NOT NULL FOREIGN KEY → user(user_id) | 发布者用户 ID |
| `name` | VARCHAR(100) | NOT NULL | 物品名称 |
| `category_id` | INTEGER | NOT NULL FOREIGN KEY → category(category_id) | 物品分类 |
| `description` | TEXT | NULL | 物品详细描述 |
| `price` | REAL | NOT NULL DEFAULT 0.0 | 价格（售卖时为人民币，交换时可设 0） |
| `trade_type` | VARCHAR(10) | NOT NULL DEFAULT 'SELL' | 交易类型：`SELL` 售卖 / `EXCHANGE` 交换 |
| `status` | VARCHAR(15) | NOT NULL DEFAULT 'ON_SALE' | 状态枚举（见下方） |
| `tags` | VARCHAR(200) | NULL | 标签，逗号分隔（如："九成新,包邮"） |
| `publish_time` | INTEGER | NOT NULL | 发布时间戳（毫秒） |

**物品状态枚举**：

| 状态值 | 说明 |
|--------|------|
| `ON_SALE` | 在售，可被搜索和发起意向 |
| `RESERVED` | 已被他人发起意向，等待确认 |
| `SOLD` | 已成交/已完成交换 |
| `OFF_SHELF` | 已下架（用户主动下架或管理员强制下架） |

**索引**：
```sql
CREATE INDEX idx_item_publisher ON item(publisher_id);
CREATE INDEX idx_item_category ON item(category_id);
CREATE INDEX idx_item_status ON item(status);
CREATE INDEX idx_item_name ON item(name);  -- 支持 LIKE 模糊搜索
```

**注意**：SQLite 不支持 ALTER TABLE 添加 FK 约束的强制检查，外键关系由应用层维护。JDBC 连接时需开启 `PRAGMA foreign_keys = ON;`。

---

### 2.4 transaction_record — 流转记录表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `record_id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 记录唯一标识 |
| `item_id` | INTEGER | NOT NULL FOREIGN KEY → item(item_id) | 涉及的物品 |
| `initiator_id` | INTEGER | NOT NULL FOREIGN KEY → user(user_id) | 发起意向的用户 |
| `status` | VARCHAR(15) | NOT NULL DEFAULT 'PENDING' | 流转状态（见下方） |
| `create_time` | INTEGER | NOT NULL | 发起时间戳 |
| `complete_time` | INTEGER | NULL | 完成时间戳（仅 COMPLETED 时有值） |
| `remark` | VARCHAR(500) | NULL | 备注信息（可选） |

**流转状态枚举**：

| 状态值 | 说明 |
|--------|------|
| `PENDING` | 待对方确认 |
| `CONFIRMED` | 对方已确认，等待完成 |
| `COMPLETED` | 已完成，双方可评价 |
| `CANCELLED` | 已取消 |

**索引**：
```sql
CREATE INDEX idx_trans_item ON transaction_record(item_id);
CREATE INDEX idx_trans_initiator ON transaction_record(initiator_id);
CREATE INDEX idx_trans_status ON transaction_record(status);
```

---

### 2.5 review — 评价表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `review_id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 评价唯一标识 |
| `record_id` | INTEGER | NOT NULL FOREIGN KEY → transaction_record(record_id) | 对应的流转记录 |
| `reviewer_id` | INTEGER | NOT NULL FOREIGN KEY → user(user_id) | 评价方用户 |
| `reviewee_id` | INTEGER | NOT NULL FOREIGN KEY → user(user_id) | 被评价方用户 |
| `rating` | INTEGER | NOT NULL CHECK(rating BETWEEN 1 AND 5) | 评分 1-5 星 |
| `comment` | VARCHAR(500) | NULL | 文字评论 |
| `create_time` | INTEGER | NOT NULL | 评价时间戳 |

**索引**：
```sql
CREATE INDEX idx_review_record ON review(record_id);
CREATE INDEX idx_review_reviewer ON review(reviewer_id);
CREATE INDEX idx_review_reviewee ON review(reviewee_id);
```

**CHECK 约束说明**：SQLite 支持 CHECK 约束，会自动校验 `rating BETWEEN 1 AND 5`。

## 三、ER 关系图（文字描述）

```
User 1 ──── 0..* Item        （一个用户发布多个物品）
User 1 ──── 0..* TransactionRecord  （一个用户发起多个流转）
User 1 ──── 0..* Review      （一个用户写多个评价）

Category 1 ──── 0..* Item    （一个分类下有多个物品）

Item 1 ──── 0..* TransactionRecord  （一个物品可以被多次发起流转）

TransactionRecord 1 ──── 0..2 Review  （一个流转记录对应双向评价）
```

## 五、建表完整 SQL

> 以下 SQL 可直接保存为 `schema.sql`（项目根目录），程序启动时自动执行。

```sql
-- 开启外键检查
PRAGMA foreign_keys = ON;

-- ==================== user ====================
CREATE TABLE IF NOT EXISTS user (
    user_id INTEGER PRIMARY KEY AUTOINCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    password_hash VARCHAR(128) NOT NULL,
    salt VARCHAR(32) NOT NULL,
    role VARCHAR(10) NOT NULL DEFAULT 'USER',
    credit_score INTEGER NOT NULL DEFAULT 100,
    create_time INTEGER NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_user_username ON user(username);
CREATE INDEX IF NOT EXISTS idx_user_role ON user(role);

-- ==================== category ====================
CREATE TABLE IF NOT EXISTS category (
    category_id INTEGER PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(50) NOT NULL UNIQUE,
    description VARCHAR(200)
);

-- ==================== item ====================
CREATE TABLE IF NOT EXISTS item (
    item_id INTEGER PRIMARY KEY AUTOINCREMENT,
    publisher_id INTEGER NOT NULL,
    name VARCHAR(100) NOT NULL,
    category_id INTEGER NOT NULL,
    description TEXT,
    price REAL NOT NULL DEFAULT 0.0,
    trade_type VARCHAR(10) NOT NULL DEFAULT 'SELL',
    status VARCHAR(15) NOT NULL DEFAULT 'ON_SALE',
    tags VARCHAR(200),
    publish_time INTEGER NOT NULL,
    FOREIGN KEY (publisher_id) REFERENCES user(user_id),
    FOREIGN KEY (category_id) REFERENCES category(category_id)
);

CREATE INDEX IF NOT EXISTS idx_item_publisher ON item(publisher_id);
CREATE INDEX IF NOT EXISTS idx_item_category ON item(category_id);
CREATE INDEX IF NOT EXISTS idx_item_status ON item(status);
CREATE INDEX IF NOT EXISTS idx_item_name ON item(name);

-- ==================== transaction_record ====================
CREATE TABLE IF NOT EXISTS transaction_record (
    record_id INTEGER PRIMARY KEY AUTOINCREMENT,
    item_id INTEGER NOT NULL,
    initiator_id INTEGER NOT NULL,
    status VARCHAR(15) NOT NULL DEFAULT 'PENDING',
    create_time INTEGER NOT NULL,
    complete_time INTEGER,
    remark VARCHAR(500),
    FOREIGN KEY (item_id) REFERENCES item(item_id),
    FOREIGN KEY (initiator_id) REFERENCES user(user_id)
);

CREATE INDEX IF NOT EXISTS idx_trans_item ON transaction_record(item_id);
CREATE INDEX IF NOT EXISTS idx_trans_initiator ON transaction_record(initiator_id);
CREATE INDEX IF NOT EXISTS idx_trans_status ON transaction_record(status);

-- ==================== review ====================
CREATE TABLE IF NOT EXISTS review (
    review_id INTEGER PRIMARY KEY AUTOINCREMENT,
    record_id INTEGER NOT NULL,
    reviewer_id INTEGER NOT NULL,
    reviewee_id INTEGER NOT NULL,
    rating INTEGER NOT NULL CHECK(rating BETWEEN 1 AND 5),
    comment VARCHAR(500),
    create_time INTEGER NOT NULL,
    FOREIGN KEY (record_id) REFERENCES transaction_record(record_id),
    FOREIGN KEY (reviewer_id) REFERENCES user(user_id),
    FOREIGN KEY (reviewee_id) REFERENCES user(user_id)
);

CREATE INDEX IF NOT EXISTS idx_review_record ON review(record_id);
CREATE INDEX IF NOT EXISTS idx_review_reviewer ON review(reviewer_id);
CREATE INDEX IF NOT EXISTS idx_review_reviewee ON review(reviewee_id);
```
