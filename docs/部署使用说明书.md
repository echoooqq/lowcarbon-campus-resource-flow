# 低碳校园资源循环流转系统 — 部署与使用说明书

> 版本：v1.0 | 最后更新：2026-11-09
> 适用人群：课程设计答辩评审、教师助教、系统演示人员、一般使用者

---

## 一、快速开始（双击即可）

```
方式一（推荐）：GitHub 仓库克隆
  → 克隆后双击根目录 run.bat，自动定位 target/dist/ 下的 jar

方式二（仅交付包）：解压 target/dist/ 到任意目录
  → 直接双击 run.bat
```

成功启动后会看到登录界面，首次使用请点 **"注册账号"** 创建新用户。

## 二、环境要求

| 项 | 要求 | 说明 |
|----|------|------|
| **操作系统** | Windows 10 / 11 64 位 | GUI 基于 Swing，跨平台但主要在 Windows 上测试 |
| **JDK** | **21 或更高** | 代码编译目标 Java 21 (class file version 65) |
| **磁盘空间** | ≥ 50 MB | Jar 包 13 MB + 运行时产生的 SQLite 数据库（KB 级） |
| **内存** | ≥ 256 MB | Swing GUI + SQLite 嵌入式运行 |
| **网络** | 不需要 | 全离线运行，无网络依赖 |

### 确认 Java 版本

```powershell
java -version
# 期望输出中包含 "21" 或更高，例如：
# openjdk version "21.0.13.0.3" 2026-10-24 LTS
```

如果系统 `java -version` 显示为 1.8 / 8 / 11 / 17，说明 PATH 里是旧版本。
推荐下载安装 [Eclipse Temurin JDK 21](https://adoptium.net/)（免费开源）。

### 安装多个 Java 怎么办？

本项目的 `run.ps1` / `run.bat` **会自动搜索并选择 JDK 21+**，
优先级为：BellSoft Liberica → 其他 BellSoft → JAVA_HOME（版本需验证） → Program Files 下的 *jdk* 目录 → 系统 PATH。

你也可以手动指定：

```powershell
# PowerShell：设置 JAVA_HOME 后运行
$env:JAVA_HOME = "C:\Program Files\BellSoft\LibericaJDK-21-Full"
.\run.ps1
```

## 三、交付包文件说明

```
dist/                            ← 交付包根目录
├── lowcarbon-system.jar         ← 主程序 fat jar（13.14 MB）
├── run.ps1                       ← PowerShell 启动脚本（推荐）
├── run.bat                       ← 批处理启动脚本
└── schema.sql                   ← 数据库建表脚本
```

### 各文件职责

| 文件 | 必需 | 说明 |
|------|------|------|
| `lowcarbon-system.jar` | ✅ 必须 | 包含：主程序 94 个 class + SQLite JDBC 驱动 + slf4j 日志 |
| `schema.sql` | ✅ 必须 | 5 张表结构 + 4 个预置分类；缺失会导致首次启动无法建表 |
| `run.ps1` | 推荐 | 智能 Java 版本检测，GUI 启动 |
| `run.bat` | 可选 | 批处理版本的启动脚本 |

### 首次启动时会发生什么

1. `run.ps1` / `run.bat` 找到 JDK 21+
2. 调用 `java -jar lowcarbon-system.jar`
3. 程序在 **Jar 同级目录** 创建 SQLite 数据库文件 `lowcarbon.db`
4. 加载同级 `schema.sql`，执行 `CREATE TABLE IF NOT EXISTS` 建表
5. 插入 4 条预置物品分类（教材 / 数码配件 / 文体用品 / 生活物资）
6. 弹出 Swing 登录窗口

> 再次启动时，若 `lowcarbon.db` 已存在，会跳过建表步骤，直接恢复之前的数据。

## 四、常见问题排查

### 4.1 启动报错：`UnsupportedClassVersionError`

```
Error: A JNI error has occurred, please check your installation and try again
Exception in thread "main" java.lang.UnsupportedClassVersionError:
  com/lowcarbon/Main has been compiled by a more recent version of the Java Runtime
  (class file version 65.0), this version only recognizes class file versions up to 52.0
```

**原因**：你当前运行的 Java 版本低于 21（版本号 52.0 对应 Java 8）。

**解决**：安装 JDK 21+，然后重新运行 `run.ps1` 或手动指定：

```powershell
# 临时指定（仅当前终端有效）
$env:JAVA_HOME = "C:\Program Files\BellSoft\LibericaJDK-21-Full"
# 或者直接用完整路径调用 Java 21
& "C:\Program Files\BellSoft\LibericaJDK-21-Full\bin\java.exe" -jar lowcarbon-system.jar
```

### 4.2 启动报错：`找不到 schema.sql`

```
WARNING: 文件系统未找到 schema.sql，改用 classpath 内置版本
```

**原因**：`schema.sql` 必须与 jar 同级。如果你把 jar 移动到别的目录了，也要把 `schema.sql` 一起移动。

**解决**：把 `schema.sql` 放回 jar 所在目录即可。

### 4.3 启动报错：数据库锁定

```
org.sqlite.SQLiteException: database is locked
```

**原因**：上一次启动的程序进程没完全退出，或者有其他进程在访问同一个 `lowcarbon.db`。

**解决**：
1. 关闭所有 LowCarbon 程序窗口
2. 打开任务管理器，结束所有 `java.exe` 进程
3. 重新启动

### 4.4 想重置所有数据

直接删除 jar 同级的 `lowcarbon.db`（以及同目录下可能的 `lowcarbon.db-shm` / `lowcarbon.db-wal`），
然后重新启动——程序会自动重新建表并插入 4 个预置分类。

```powershell
# PowerShell 一键清理
Remove-Item .\lowcarbon.db, .\lowcarbon.db-shm, .\lowcarbon.db-wal -ErrorAction SilentlyContinue
```

### 4.5 想把数据库存到别的位置

```powershell
# 用系统属性覆盖默认路径
java '-Dlowcarbon.db.path=D:\mydata\lowcarbon.db' -jar lowcarbon-system.jar
```

或者在 `run.ps1` 里把启动命令改成：

```powershell
& $java21 '-Dlowcarbon.db.path=D:\mydata\lowcarbon.db' '-jar' $jar
```

## 五、功能使用指南

### 5.1 账号体系

| 操作 | 说明 |
|------|------|
| 注册 | 登录界面点"注册账号"，填写用户名 + 密码（密码 ≥ 6 位） |
| 登录 | 注册后回到登录界面，用账号密码登录 |
| 用户角色 | 注册默认为普通用户（USER），包含发布/交易/评价权限 |
| 管理员 | **无预置管理员账号**。若需要管理员权限，需修改数据库：UPDATE user SET role='ADMIN' WHERE user_id=X |

### 5.2 核心功能入口（登录后）

| 功能 | 入口 | 说明 |
|------|------|------|
| 浏览物品 | 侧边栏 → "物品大厅" | 支持分类筛选、关键词搜索、价格区间、组合筛选 |
| 发布物品 | 侧边栏 → "发布物品" | 选择分类、填写描述、设置价格（0 = 免费赠送） |
| 管理我的物品 | 侧边栏 → "我的物品" | 下架已发布的物品、查看状态 |
| 发起交易 | 物品详情 → "求购/申请" | 自动从 ON_SALE → RESERVED |
| 我的流转 | 侧边栏 → "流转记录" | 买家可取消；卖家可同意/拒绝；双方同意后完成 |
| 评价 | 交易完成后 | 双方互相评分（1~5 星），评价影响信用分 |
| 统计报表 | 侧边栏 → "数据统计" | 成交统计 / 低碳贡献 / 导出 CSV |
| 管理员后台 | 侧边栏 → "管理后台" | 强制下架、重置密码、用户列表（需要 ADMIN 角色） |

### 5.3 交易状态流转

```
创建交易(PENDING) → 卖家同意(APPROVED) → 完成交易(COMPLETED)
                 ↓                      ↓
              卖家拒绝(REJECTED)      买家取消(CANCELLED)
```

物品状态同步：`ON_SALE → RESERVED → SOLD`（拒绝/取消后回退 ON_SALE）

### 5.4 信用分规则

| 行为 | 信用分变化 | 说明 |
|------|-----------|------|
| 新注册 | +0（初始 100） | 默认信用分 100 |
| 被别人评价 N 星 | +(N - 3) | 5 星 +2，4 星 +1，3 星 +0，2 星 -1，1 星 -2 |
| 自己评价他人 | +1 | 评价完成后给自己 +1 |
| 主动下架物品 | -5 | 发布者扣 5 分（观察者模式自动） |
| 被管理员强制下架 | -5 | 同上 |
| 信用分上下限 | 0 ~ 999 | 超出自动钳位 |

### 5.5 低碳指标

| 指标 | 计算方式 |
|------|---------|
| 累计节约碳排放 | 成交物品数 × 6 kg CO₂e |
| 节约量参考 | 每流通 1 本教材 ≈ 节约 6kg CO₂（含造纸 + 运输） |

## 六、开发与二次部署

### 6.1 从源码构建

```bash
# 前提：已安装 JDK 21 + Maven 3.9+
mvn clean package -DskipTests

# 产物位置
# target/dist/lowcarbon-system.jar   ← fat jar
# target/dist/run.ps1                ← 启动脚本（请手动复制）
# schema.sql                         ← 请手动复制到 dist/
```

### 6.2 手动打包 fat jar（无 Maven 环境）

```powershell
$java21 = "C:\Program Files\BellSoft\LibericaJDK-21-Full\bin"

# 1. 编译
javac -encoding UTF-8 -cp "sqlite-jdbc.jar;slf4j-api.jar;slf4j-simple.jar" -d target/classes src/main/java/**/*.java

# 2. 解压依赖
New-Item -ItemType Directory target/staging
Copy-Item target/classes/* target/staging -Recurse
Set-Location target/staging
jar xf sqlite-jdbc.jar
jar xf slf4j-api.jar
jar xf slf4j-simple.jar
Remove-Item META-INF/*.SF, META-INF/*.RSA, META-INF/*.DSA

# 3. 创建 manifest
Set-Content -Path target/MANIFEST.MF -Value "Main-Class: com.lowcarbon.Main`n`n" -Encoding ASCII

# 4. 打包 fat jar
jar cfm target/dist/lowcarbon-system.jar target/MANIFEST.MF .
```

### 6.3 运行全部测试

```powershell
$java21 = "C:\Program Files\BellSoft\LibericaJDK-21-Full\bin"
$cp = "target/classes;target/test-classes;sqlite-jdbc.jar;slf4j-api.jar;slf4j-simple.jar;junit.jar;hamcrest.jar"
& $java21 "-Dlowcarbon.db.path=lowcarbon_test.db" -cp $cp org.junit.runner.JUnitCore org.junit.runner.JUnitCoreRunner
# 原有 264 + 集成 14 = 278 个测试全部通过
```

### 6.4 数据库备份

```powershell
# 拷贝整个数据库文件即可
Copy-Item .\lowcarbon.db .\lowcarbon_backup_$(Get-Date -Format yyyyMMdd).db
```

### 6.5 日志位置

项目使用 JDK 内置 `java.util.logging`，默认输出到 **控制台**（GUI 模式下不可见）。
如需写入文件，在 `DatabaseManager` 启动前设置：

```java
LogManager.getLogManager().readConfiguration(
    Main.class.getResourceAsStream("/logging.properties"));
```

## 七、技术栈速查

| 层 | 技术 | 说明 |
|----|------|------|
| 语言 | Java 21 LTS | — |
| GUI | Swing（事件驱动） | 不依赖第三方 GUI 库 |
| 数据库 | SQLite 3.x | 嵌入式，单文件，零配置 |
| ORM | 自研 DAO + PreparedStatement | 无 Hibernate，防御性编程 |
| 加密 | SHA-256 + 盐值 | 密码安全存储 |
| 日志 | java.util.logging | JDK 内置 |
| 测试 | JUnit 4.13.2 | 单元 + 集成，共 278 个 |
| 构建 | Maven + 手动 fat jar | 无 Maven 也能构建 |

### 设计模式落地

| 模式 | 位置 | 用途 |
|------|------|------|
| **单例** | `DatabaseManager` + `ServiceFactory` | 全局唯一数据库连接 + Service 实例 |
| **工厂** | `DaoFactory` + `ServiceFactory` | 集中创建 DAO/Service，解耦调用方与实现 |
| **策略** | `ItemService.searchOnSale` | 分类/关键词/价格区间自由组合筛选 |
| **观察者** | `ItemStatusSubject` ↔ `CreditAdjustObserver` | 物品下架 → 自动扣信用分（松散耦合） |
